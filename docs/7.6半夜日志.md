# 7.6 半夜日志

## 用户提示词

1. "你先阅读整个项目，明确项目的架构和技术细节"
2. "给我定位负责左右滑动的代码位置、负责'知汇卡能力中枢'的位置，负责复习页面的代码位置"
3. "左右滑动功能，从设置向指数滑动，指数界面不从左侧进入，而是从右侧进入，不符合常识"
4. "从采集回到回流箱新出现了相同问题，原来他是正常的，修改"
5. "我的意思是，你最开始改的对！只是刚刚改对了之后从采集回到回流箱出现了小问题"

## 问题诊断

- **Tab 顺序**: collections(0) → capture(1) → review(2) → dashboard/指数(3) → settings/设置(4)
- **根因**: NavHost 的 `enterTransition` 始终 `initialOffsetX = fullWidth`（一律从右侧滑入），不区分翻页方向
- 从设置(右)向指数(左)时，指数界面应从左侧进入，实际却从右侧进入

## 最终修改

### 1. `AppScaffold.kt`

- 新增 `import androidx.compose.runtime.MutableState`
- `HuoyejiaScaffold` 新增参数: `tabNavDirection: MutableState<Float>`
- `navigateToMainTab` 中根据新旧 tab 索引计算方向:
  - `targetIndex > currentIndex` → dir=1f (向右翻页)
  - `targetIndex < currentIndex` → dir=-1f (向左翻页)

### 2. `MainActivity.kt`

- 新增 `import androidx.compose.runtime.remember`
- 新增状态: `val tabNavDirection = remember { mutableStateOf(1f) }`
- `HuoyejiaScaffold` 传入 `tabNavDirection`
- NavHost 过渡动画改为方向感知:
  - `enterTransition`: `initialOffsetX = fullWidth * dir` — 右翻从右侧滑入，左翻从左侧滑入
  - `exitTransition`: `targetOffsetX = -fullWidth * dir` — 对称平移，与 enter 等速同步
  - `popEnterTransition` / `popExitTransition`: 保持原逻辑不变（仅 popBackStack 触发）

### 3. 与第一版的区别

第一版 exitTransition 用了 `-fullWidth/3 * dir`（1/3 屏宽），导致向左翻时 exit 只平移 1/3、enter 平移全屏，视觉上不对称。最终版改为 `-fullWidth * dir`（全屏平移），exit 和 enter 等速同步，形成推送翻页效果。

## 效果

| 操作 | 翻页方向 | 新页面进入方向 | 旧页面退出方向 |
|---|---|---|---|
| 设置 → 指数 | 向左 | 从左侧滑入 | 向右滑出 |
| 指数 → 复习 | 向左 | 从左侧滑入 | 向右滑出 |
| 采集 → 回流箱 | 向左 | 从左侧滑入 | 向右滑出 |
| 回流箱 → 采集 | 向右 | 从右侧滑入 | 向左滑出 |
| 复习 → 指数 | 向右 | 从右侧滑入 | 向左滑出 |

### 提示词: "我不希望复习卡片出现两个完全不相关的知识点混在一块"

**策略**: API 层面做三层隔离——前端硬拦截 + prompt 结构化约束

#### 1. `ReviewCardGenerator.kt` — 程序化硬拦截

- 新增 `isRelatedByTopic()`: 对比 current.topic 和 related.topic，不匹配则降级为 `single_note`
- 新增 `isRelatedByVector()`: 实时查询 embedding 计算余弦相似度，< 0.75 则降级
- `REVIEW_CARD_GENERATOR_MIN_RELATION`: 0.70f → **0.78f**（提高关系置信度门槛）
- 新增最小向量相似度阈值: **0.75f**
- 新增导入: `NoteWithEmbedding`, `VectorCodec`

逻辑：找到关联笔记后，通过 topic 对比和向量相似度双重校验，任一不通过则**不传关联笔记**，仅基于当前笔记出题。

#### 2. `RemoteBlueLMAdapter.kt` — 补齐结构化隔离指令

- 在 review card 生成 prompt 末尾新增 `isolation_policy=only_current_note; related_optional_max_one; do_not_mix_topics`
- 与 `ServerBlueLMAdapter` 和 `server/ai.py` 保持一致，消除直连 LLM 路径的结构化指令缺失
