# 多维加权归一的数字囤积指数与阈值触发干预

> 不是统计你存了多少，而是量化你"浪费了多少认知机会"。

我们第一次让"收藏癖"从一个说不清的感觉，变成了一个能算出来的数字。

- **熵权法自适应赋权的多因子融合模型**：采集压力系数、未读衰减梯度、回流闭合率、内容重复度、处理延迟比——五项因子经熵权法动态赋权后融合归一，输出 0–100 单一指数，四级阈值映射认知状态。仅需 5 条采集即可生效，在行为定型前介入引导。
